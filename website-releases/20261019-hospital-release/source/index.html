A shared foundation

Data moves healthcare and life sciences forward.

Open-H brings academic groups, clinicians, and industry teams together to build research resources that are useful beyond any single institution or platform.

Our current initiatives span embodied robotic data, endoluminal robotics, raw ultrasound channel data, and 4D cardiac and respiratory imaging.

Current work

Five initiatives, one open ecosystem.

Each effort creates a practical route for the community to contribute data, methods, and domain expertise.

Public dataset 01

Open-H-Embodiment

A community-driven dataset initiative building the shared foundation to train and evaluate generalist vision-language-action models for healthcare robotics.

Public dataset 03

Open-H-RF

An open effort to create high-quality raw ultrasound channel data and foundation models for reconstruction, flow, quantitative imaging, motion estimation, and interpretation.

Project website ↗ Hugging Face dataset ↗ View GitHub repository ↗
New initiative 04

Open-H-4D

A collaborative effort to bring together 4D CT, MRI and ultrasound of cardiac and respiratory motion, supporting open foundation models of human physiology.

View GitHub repository ↗
New initiative 05

Open-H-Hospital

Open-H-Hospital is a community‑driven dataset initiative with the goal to accelerate physical AI and spatial intelligence for robotics-mediated hospital workflows through large-scale acquisition of multimodal data (e.g., video, kinematic, tactile, and operations data).
